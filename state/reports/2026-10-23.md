## Tool errors / notes

- **Ad placement cap:** The first save_post was rejected with "can not accept any
  more opportunities." The ad network auto-accepts a rolling set of opportunities and
  caps how many can be held accepted at once; placing FRESH offer IDs from
  list_ad_offers triggers a new accept that exceeded the cap. Fix applied: embed the
  already-accepted opportunity UUIDs from list_ad_opportunities(status accepted)
  instead, which does not trigger a new accept. Second save succeeded with all three
  ads placed. (Lesson recorded in state/ad-log.json.)
- **email_settings keys:** save_post's email_settings uses email_subject_line /
  email_preview_text, not subject_line / preview_text. The first save silently
  defaulted the subject to the post title; fixed with a follow-up edit_post. (Lesson
  recorded in state/ad-log.json.)
- **WebFetch blocked:** WebFetch returned DNS errors (ENOTFOUND) for all external
  hosts in this run environment, so story verification relied on WebSearch result
  summaries, which corroborated each story across multiple credible outlets. Image
  uploads still worked because beehiiv fetches image URLs server-side.
