## Tool errors / lessons

- **Ad placement (important):** The first two save_post attempts failed. With
  fresh list_ad_offers ids and kind="primary" it returned "No 'primary' ad slot
  is available in this post"; with kind omitted it returned "can not accept any
  more opportunities." Root cause: the ad network caps how many opportunities
  the publication can ACCEPT, and several were already auto-accepted. Fix:
  embed the already-accepted opportunity UUIDs from
  list_ad_opportunities(status="accepted") instead of fresh offers, and omit
  data-advertisement-kind so beehiiv auto-selects the creative. Third attempt
  placed all 3 slots. This lesson is recorded in post-authoring-contract.md.
